# About Me Chaos

Адаптивний сайт-візитка Ярослава про навчання веброзробці, AI та створення цифрових продуктів.

## Технології

- HTML5
- CSS3
- JavaScript
- WebGL canvas
- Git та GitHub

## Функції

- адаптивна сторінка «Про мене»;
- світла й темна тема;
- Halloween-хаос із декоративними ефектами;
- інтерактивна творча лабораторія;
- картки навичок із прикладами коду;
- режим фокусу для спокійного читання без зайвих ефектів.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний статичний сервер у папці проєкту.

## Безпека

Файл `.env` використовується лише як демонстрація для навчального завдання і містить вигадане значення. Він доданий до `.gitignore`, тому не публікується на GitHub. Справжні API-ключі та паролі до проєкту не додавалися.

## Зміни для Модуля 5

У гілці `feature/focus-mode` за допомогою AI-агента додано режим фокусу. Він приглушує декоративні елементи, прибирає зайву візуальну увагу та показує повідомлення про стан функції. Зміни переглядаються через Git, а експериментальні правки можна скасувати без втрати основної роботи.
